# 泊识停车

作者：艾丝妲的狗

车牌识别停车场管理系统：上传车辆照片 → 识别车牌 → 入场 / 出场结算 → 记录与运营看板。

**完整操作说明请看 [使用教程.md](./使用教程.md)。**

## 快速开始

```bash
npm install
npm run dev
```

浏览器打开终端提示的地址（默认 `http://localhost:8080`）。

1. 首页点击 **试用示例图片**（车牌 `京A66666`）
2. **确认入场**
3. 在场卡片上点 **出场** 完成结算

车牌自动识别需要环境变量 `XAI_API_KEY`；没有密钥时可以手动输入车牌，其余功能不受影响。
